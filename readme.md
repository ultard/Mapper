# Картографическое приложение

Веб-приложение для работы с OpenStreetMap и Яндекс.Картами, позволяющее добавлять маркеры и строить линии между точками.

## Функциональность

- **Выбор карты**: переключение между OpenStreetMap и Яндекс.Картами
- **Выбор города**: Москва, Санкт-Петербург, Новосибирск, Екатеринбург
- **Работа с точками**:
    - Добавление маркеров по координатам
    - Генерация случайных точек в пределах выбранного города
    - Построение линии между двумя точками
    - Валидация координат (проверка на вхождение в границы города)

## Как пользоваться

### Начало работы

1. Выберите карту из выпадающего списка (OpenStreetMap или Яндекс.Карты)
2. Нажмите кнопку "Инициализировать карту" (Нажимать каждый раз не нужно, только при первом запуске или смене карты)
3. Выберите город


### Работа с точками

#### Ручное добавление точек
1. Введите координаты (широта и долгота) для Точки 1 и Точки 2
2. Нажмите кнопку "Обновить маркеры" для размещения точек на карте

#### Автоматическая генерация точек
1. Нажмите кнопку "Сгенерировать случайные точки"
2. Случайные координаты будут созданы в пределах выбранного города и отображены на карте

#### Построение линии
1. После размещения двух точек нажмите кнопку "Построить линию"
2. Между точками будет проведена линия, карта автоматически изменит масштаб для отображения обеих точек

## Технические особенности

- Карта динамически обновляет свой размер при изменении видимости контейнера
- Поддержка как Leaflet (OpenStreetMap), так и API Яндекс.Карт
- Проверка координат на нахождение в пределах выбранного города
